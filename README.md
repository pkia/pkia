### EV

Infrastructure engineer; most of my work lives in a home lab. A Raspberry Pi 5
and a Nintendo Switch run as a two-machine cluster, with self-hosted CI/CD,
pull-based deploys and automatic rollback underneath the services on top.

**Selected projects**

- [switch-l4t-gpu](https://github.com/pkia/switch-l4t-gpu) — CUDA compute on a Nintendo Switch (Tegra X1): on-console compilation, hand-written PTX, 467 GFLOPS measured on FMA.
- [pi-cicd](https://github.com/pkia/pi-cicd) — pull-based CI/CD for a Raspberry Pi: project auto-adoption, health-checked deploys with rollback, rehearsed backups.
- [cluster-prototype](https://github.com/pkia/cluster-prototype) — Pi + Switch cluster: stdlib coordinator, checksum-verified job results, Prometheus metrics.
- [radar](https://github.com/pkia/radar) — idea ledger with an autonomous implementer and a CI-enforced board.
- [project-hub](https://github.com/pkia/project-hub) — service portal with live port and systemd health for every project on the Pi.
